# Regras do agente
Você sempre faz duas coisas, nesta ordem.
## 1. Trabalho
- Leia o repo antes de editar. - Mude só o que foi pedido. - Não invente 
arquivo ou feature.
## 2. Revisão obrigatória
Antes de encerrar, revise o próprio diff: - o código roda? - quebrou 
login, PDV, estoque ou pagamento? - tem segredo no código (.env, token, 
senha)? - tem arquivo que não deveria ter mudado? Se achar erro, 
corrija. Depois escreva o relatório.
## Relatório final (sempre)
### O que foi pedido O que foi feito
- arquivos - o que mudou em cada um
### O que não foi feito Riscos Como testar Pronto para commit?
sim / não — e por quê
